# Barangay-Web

**Barangay-Web** is a web application designed to streamline and enhance the management of barangay operations. Built using React and Vite, it leverages modern web development tools to provide an efficient and responsive user experience.

## 🚀 Features

- **Resident Management**: Add, update, and view resident information.
- **Document Issuance**: Generate and manage barangay documents such as certificates and clearances.
- **Announcements**: Post and manage community announcements.
- **Responsive Design**: Optimized for various devices to ensure accessibility.

## 🛠 Technologies Used

- **Frontend**: [React](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Linting**: [ESLint](https://eslint.org/) for code quality
- **Build Tool**: [Vite](https://vitejs.dev/) for fast development and optimized builds
